# Classics public/private boundary

Public Git is for independently authored translator/runtime/platform/tooling/test code and safe
reverse-engineering knowledge. Do not commit original executables/assets, mechanically decompiled or
reconstructed copyrighted source, executable-derived private images/builds, or other proprietary
title data.

Governed private title material lives under CSJS Drive and is projected into agent runs according to
Unity1 Control policy. Context exports are tracked-files-only. Private-reference agent runs protect
`.git` and suppress patch-body evidence. Promotion of public changes must pass
`unity1-classics-public-boundary-audit` and human/project-thread review.
