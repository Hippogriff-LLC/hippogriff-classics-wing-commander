# Hippogriff Classics — Wing Commander

Hippogriff Classics title project for independently reconstructing the actual original DOS
implementation as a portable native program suitable for WebAssembly/browser and later modern
native targets.

This is not an inspired-by clone and DOSBox is not the final architecture. Emulation may be used
for reference/testing when useful.

Original/proprietary game bytes and mechanically reconstructed copyrighted implementation are
private inputs/derived artifacts and must not be committed to this public repository.
